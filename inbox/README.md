# inbox — входящие материалы

Сюда человек кладёт всё, что относится к новому запросу: бриф, документы, таблицы, список ссылок. При создании проекта агент копирует файлы в `projects/<id>/materials/` и регистрирует каждый как источник.

Сейчас здесь лежат материалы демонстрационного проекта:

| Файл | Что это | Откуда |
|---|---|---|
| `megafon-brief.md` | Бриф «Связь для близких и собственных устройств» — текст PDF «Пример брифа» без сокращений | Материалы партнёра (МегаФон) на странице номинации MGIMO×AI Challenge |
| `megafon-pokazateli.csv` | Таблица исходных показателей и размеров рынка из того же брифа | Собрана из брифа вручную, числа не менялись |

Все числа в брифе учебные, оператор вымышленный. Закрытых данных МегаФона и других компаний в репозитории нет.

Не кладите сюда файлы с персональными данными и секретами.
