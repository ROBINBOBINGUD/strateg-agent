# Интервью и модельные респонденты

Методика: `knowledge/08-intervyu-i-modelnye-respondenty.md`. Тема: $ARGUMENTS

## Когда использовать

- Нужно понять последовательность действий клиента, а историй реальных клиентов нет → гайд для реальных интервью плюс модельные респонденты для поиска гипотез.
- Нужно проверить, понятна ли формулировка сообщения → модельные респонденты.
- Человек принёс записи или конспекты реальных интервью → разбор.

Чего этим методом доказать нельзя: спрос, распространённость проблемы, готовность платить. Для этого нужны данные о реальных клиентах — запиши это в пробелы.

## Гайд

Сохрани `outputs/interviews/guide.md`: цель; кого зовём (признаки отбора); 8–12 вопросов о прошлом поведении («расскажите про последний случай, когда…»), без наводящих и без вопросов о намерениях; что считаем сигналом, а что шумом.

## Модельные респонденты

1. Опиши 3–4 разные персоны: роль в ситуации, возраст и уклад в общих чертах, опыт с продуктом, отношение (в том числе скептик и тот, кому проблема безразлична). Без имён реальных людей.
2. Запусти субагента `respondent` по одному на персону (параллельно): роль, ситуация, вопросы из гайда.
3. Сохрани каждую беседу в `outputs/interviews/synthetic-<роль>.md` — первой строкой пометка «СИНТЕТИКА» из ответа субагента.
4. Зарегистрируй: `python tools/strateg.py source add --type synthetic --title "Модельный респондент: <роль>" --ref "outputs/interviews/synthetic-<роль>.md" --reliability C`.
5. Наблюдения занеси в `evidence.jsonl` с видом `synthetic`. В текстах результатов они называются «гипотеза из синтетического интервью» и никогда не стоят в разделе фактов.

## Разбор интервью (реальных или синтетических)

`outputs/interviews/analysis.md`: цитата → наблюдение → гипотеза → как проверить на данных. Повторяющееся у разных респондентов — кандидат в гипотезы; единичное — отметка «один случай».

## Реальные интервью

Только с согласия собеседника. В репозиторий — обезличенный конспект: без имён, телефонов, адресов и других персональных данных. Источник регистрируется с типом `interview`.
