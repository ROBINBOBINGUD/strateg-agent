# Шаг `support`: поддержка решения

Методика: `knowledge/10-podderzhka-reshenij.md`. Используй, когда стратегия принята и человек возвращается: «что у нас по проекту», «что решать сейчас», «пора ли пересматривать».

1. `python tools/strateg.py status` и `python tools/strateg.py decisions due`.
2. Скажи человеку:
   - **что решать сейчас** — решения, у которых подошла дата или сработало условие пересмотра;
   - **какие основания устарели** — решения, опирающиеся на отозванные утверждения;
   - **что отслеживать** — показатель и ответственный по каждому действующему решению;
   - **чего ждём** — данные, которые должны появиться к следующей точке решения.
3. Новое решение человека запиши: `python tools/strateg.py decisions add …`. Изменившееся — не правь задним числом: добавь новое и объясни связь со старым в `--decision`.
4. Появились новые данные → процедура `revise`.
5. Уроки, полезные для будущих проектов, сохрани в память:
   `python tools/strateg.py memory add --kind lesson --text "…" --origin "<id проекта>, <E-id>"`.
   Заметка памяти — вывод агента, а не факт: в новом проекте её можно использовать только как гипотезу, пока она не подтверждена источником. Устаревшую заметку отзывай: `python tools/strateg.py memory revoke <M-id> --reason "…"`.
6. При первом входе на этот шаг: `python tools/strateg.py step support start`. Шаг остаётся открытым, пока проект живёт.
