# Шаг `final`: сборка и самопроверка

1. `python tools/strateg.py step final start`.
2. Собери `outputs/STRATEGIYA.md` — один документ, который руководитель может прочитать без остальных файлов:
   - **В начале, на один экран:** какое решение просим принять и к какому сроку; кому помогаем первым; что предлагаем; какой результат ожидаем (диапазоном); что для этого нужно; главный риск.
   - Если бриф человека задаёт структуру документа — основная часть идёт по ней. Иначе: проблема клиента → варианты и выбор → продуктовая стратегия → коммуникационная стратегия → план проверки → план по периодам, ресурсы, риски → просьба к руководителю.
   - Расчёты стоят рядом с решениями, которые они обосновывают.
   - В конце: «Что мы знаем, предполагаем и не знаем» (сводная таблица) и «Источники» (из `sources.md`).
   - Ссылки `[E-…]`, `[S-…]` сохраняются. Гипотезы, прогнозы, допущения и синтетика названы прямо.
3. Независимая критика: субагент `critic` читает `STRATEGIYA.md` целиком. Критичные и важные замечания исправь; с чем не согласен — оставь в разделе «Открытые возражения» с объяснением.
4. Самопроверка по списку:
   - `python tools/strateg.py check` — ноль ошибок; предупреждения просмотрены;
   - вариантов не меньше трёх, среди них «оставить как есть» и «закрыть»;
   - продуктовая и коммуникационная стратегии говорят об одной аудитории и одном составе запуска;
   - каждое обещание клиенту выполнимо продуктом;
   - у плана проверки есть порог, срок, группа сравнения и правила остановки;
   - пробелы названы, и для каждого сказано, как его закрыть.
5. Запиши решения в журнал (по одному на каждое обязательство):
   `python tools/strateg.py decisions add --decision "…" --owner "…" --metric "…" --review-condition "…" --review-date YYYY-MM-DD --based-on E-…,E-…`.
6. Приёмка: `python tools/strateg.py gate ask "Принять стратегию или вернуть на доработку?" --options "Принять|Доработать" --step final`. Покажи человеку первый экран документа, расходы и время (`python tools/strateg.py cost`) и список открытых возражений. Остановись.
7. После ответа: `gate answer "…"`. «Принять» → `python tools/strateg.py step final done --outputs outputs/STRATEGIYA.md`, затем коротко: что отслеживать и когда вернуться (процедура `support`). «Доработать» → правка нужного шага с `--redo`.
