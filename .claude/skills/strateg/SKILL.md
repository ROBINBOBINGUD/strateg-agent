# Стратег: начать или продолжить

Запрос человека: $ARGUMENTS

## 1. Определи, где мы

Выполни `python tools/strateg.py status` (если статус уже пришёл в начале сеанса — используй его).

- **Активного проекта нет или человек явно принёс новую задачу** → раздел 2.
- **Есть активный проект** → раздел 3.

## 2. Новый проект

1. Придумай идентификатор: латиница, дефисы, до 30 символов, по сути задачи.
2. `python tools/strateg.py new <id> --title "<короткое название по-русски>"`.
3. Скопируй материалы человека из `inbox/` (и те, что он назвал) в `projects/<id>/materials/`, не изменяя их. Имена файлов сохрани.
4. Переходи к шагу `intake` (процедура `.claude/skills/intake/SKILL.md`).

## 3. Продолжение

1. Скажи человеку в двух строках: проект, какой шаг закрыт последним, что делаем сейчас.
2. Если в статусе есть вопрос к человеку:
   - ответ уже есть в запросе → `python tools/strateg.py gate answer "<ответ своими словами, без искажений>"` и продолжай;
   - ответа нет → повтори вопрос и остановись.
3. Возьми «следующее действие» из статуса и выполни процедуру этого шага.

## 4. Как вести работу

- Между решениями человека работай самостоятельно: закрыл шаг — сразу начинай следующий. За один сеанс можно пройти несколько шагов.
- На шагах с решением человека (`intake` — подтверждение постановки, `options` — выбор направления, `final` — приёмка) задай вопрос через `gate ask`, покажи человеку то, что нужно для выбора, и остановись.
- После каждого шага — отчёт в 4–6 строк: что сделано; главное, что узнали; чего не знаем; что дальше; расходы сеанса (`python tools/strateg.py cost`).
- Человек попросил исправить результат → `step <id> start --redo --note "…"`, правка, `check`, `step <id> done`.
- Человек принёс новые данные по закрытому проекту → процедура `revise`.
- Нужны интервью или проверка формулировок → процедура `interviews`.

## 5. Когда останавливаться

Останавливайся, когда: ждёшь решения человека; шаг `final` принят; человек сказал «стоп». Перед остановкой убедись, что состояние сохранено: `python tools/strateg.py status` показывает правильный шаг. Тогда новый чат продолжит с этого места.
