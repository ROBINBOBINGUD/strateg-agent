# projects — задачи руководителя

Одна папка — одна задача. Активный проект записан в файле `ACTIVE`; команда `python tools/strateg.py use <id>` его переключает, `python tools/strateg.py projects` показывает список.

| Папка | Что это |
|---|---|
| `_template/` | заготовка, из которой команда `new` создаёт проект |
| `family-multisim/` | демонстрационный проект по брифу МегаФона «Связь для близких и собственных устройств»: пройден неинтерактивными запусками, для каждого захода известны точное время и стоимость |

Внутри проекта:

| Файл или папка | Содержимое | Кто пишет |
|---|---|---|
| `materials/` | исходные материалы человека, без изменений | агент копирует из `inbox/` |
| `sources.jsonl` → `sources.md` | реестр источников `S-001…`: тип, ссылка, издатель, дата, надёжность | агент через CLI |
| `evidence.jsonl` → `evidence.md` | реестр утверждений `E-001…`: вид, текст, источники, уверенность, статус | агент |
| `outputs/` | результаты шагов и итоговый документ `STRATEGIYA.md` | агент |
| `analysis/` | расчёты: скрипт `.py` и его результат `.md` | агент и субагент `analyst` |
| `decisions.jsonl` | журнал решений: ответственный, показатель, условие и дата пересмотра, основания | агент через CLI |
| `state.json` → `STATUS.md` | шаги, ожидание ответа человека, история решений | только CLI |
| `journal.jsonl` | что агент делал: поиск, чтение, запись, расчёты, субагенты, ошибки | хуки и CLI |
| `costs.jsonl` | время, токены и стоимость по сеансам | хук и команда `cost import` |

Файлы `.md` рядом с реестрами — читаемые представления; их пересоздаёт команда `check`.
