# Стратег — ИИ-агент руководителя цифрового продукта

«Стратег» — папка с инструкциями, знаниями и инструментами. Откройте её в Claude Code (или Codex, Cursor), и агент проведёт руководителя продукта от размытого запроса до согласованных продуктовой и коммуникационной стратегий, а после решения будет хранить его основания и пересматривать выводы при новых данных.

Это не автономная программа: всю работу делает LLM-агент среды разработки по правилам из этой папки. Скрипты отвечают только за то, что надёжнее делать без модели: состояние задачи, проверку ссылок на источники, журнал и учёт расходов.

Работа создана для номинации «ИИ-проект» MGIMO×AI Challenge (задание «Стратег Фабрики продуктов», партнёр — МегаФон). Демонстрационный проект по брифу партнёра: [`projects/svyaz-dlya-blizkih/`](projects/svyaz-dlya-blizkih/), итоговый документ — `outputs/STRATEGIYA.md`.

## Быстрый старт

Что нужно заранее:

| Что | Зачем | Платно? |
|---|---|---|
| Claude Code 2.1.277 или новее | среда, в которой работает агент | подписка Claude (Pro, Max) или ключ Anthropic API |
| Python 3.10+ (команда `python`; на macOS и Linux подойдёт `python3`) | CLI и хуки, только стандартная библиотека | нет |
| Git for Windows (только Windows) | хуки выполняются в Git Bash | нет |
| Доступ в интернет | поиск и чтение открытых источников встроенными инструментами WebSearch и WebFetch | входит в подписку; по API — по тарифу |

Других зависимостей, ключей и скрытых настроек нет. Устанавливать пакеты не нужно.

```bash
git clone <адрес репозитория> strateg && cd strateg
python -m unittest discover -s tools/tests   # проверка: 4 теста, все зелёные
claude                                        # при первом запуске подтвердите доверие к папке
```

В чате напишите запрос своими словами, например:

```
/strateg Я руководитель направления «…». Бриф и таблица лежат в inbox/. Нужно понять, … К концу квартала я должен решить, …
```

Материалы (бриф, документы, таблицы, список ссылок) заранее положите в `inbox/`.

## Что произойдёт дальше

Агент идёт по девяти шагам и трижды останавливается за решением человека:

| Шаг | Что делает агент | Что получает человек | Решение человека |
|---|---|---|---|
| 1. Постановка | уточняет решение, срок, ограничения; задаёт только блокирующие вопросы | `outputs/01-postanovka.md` | **подтвердить постановку** |
| 2. Сбор материалов | разбирает документы и таблицы, регистрирует источники | `sources.md` | — |
| 3. Исследование | строит план от вопросов, меняющих решение; субагенты ищут источники и считают | `outputs/02-plan-issledovaniya.md`, `outputs/03-kartina-situacii.md`, `evidence.md` | — |
| 4. Варианты | не меньше трёх разных, включая «оставить как есть» и «закрыть»; сильные возражения | `outputs/04-varianty.md` | **выбрать направление** |
| 5. Продуктовая стратегия | аудитория, альтернативы, предложение, отказы, экономика | `outputs/05-produktovaya-strategiya.md` | — |
| 6. Коммуникационная стратегия | барьер, сообщение, подтверждение, роль каналов; проверка «обещание не больше продукта» | `outputs/06-kommunikacionnaya-strategiya.md` | — |
| 7. План проверки | ожидаемое изменение, сравнение, срок, порог, правила остановки | `outputs/07-plan-proverki.md` | — |
| 8. Сборка | единый документ, независимая критика, журнал решений | `outputs/STRATEGIYA.md` | **принять или вернуть** |
| 9. Поддержка | что решать сейчас, какие основания устарели, пересмотр при новых данных | обновлённые выводы | по ситуации |

В любой момент можно остановить агента, уточнить задачу или попросить переделать шаг: «переделай варианты, добавь вариант с партнёром».

## Продолжение после перерыва

Закройте чат в любой момент. Состояние задачи лежит в файлах проекта, а не в памяти чата. В новом чате хук при старте сам передаёт агенту статус: какой шаг закрыт, какой следующий, какой вопрос ждёт ответа. Достаточно написать «продолжай» или сразу ответить на вопрос агента. Выполненные шаги не повторяются.

## Команды

Агент вызывает их сам; человеку они полезны, чтобы посмотреть, что происходит.

| Команда | Что показывает или делает |
|---|---|
| `python tools/strateg.py status` | шаги, вопрос к человеку, следующее действие, расходы |
| `python tools/strateg.py journal` | журнал: что агент искал, читал, считал и записывал |
| `python tools/strateg.py cost` | время и стоимость по сеансам |
| `python tools/strateg.py check` | проверка: у каждой ссылки в тексте есть источник, факты не опираются на синтетику |
| `python tools/strateg.py impact E-012` | какие выводы, разделы и решения зависят от утверждения или источника |
| `python tools/strateg.py decisions due` | какие решения пора пересмотреть и почему |
| `python tools/strateg.py search "удержание"` | поиск по методикам, памяти и утверждениям проекта |
| `python tools/strateg.py new <id> --title "…"` | новый проект |

Полный список — `python tools/strateg.py --help`, форматы файлов — [`docs/spec-cli.md`](docs/spec-cli.md).

## Как устроена папка

```
AGENTS.md            постоянные правила агента (единые для Claude Code, Codex, Cursor)
CLAUDE.md            импорт AGENTS.md и особенности Claude Code
.claude/
  skills/            12 процедур: strateg (вход), 9 шагов, interviews, revise
  agents/            4 субагента: researcher, analyst, critic, respondent
  settings.json      разрешения и хуки
knowledge/           методические знания: 10 карточек и оглавление
memory/              память между проектами (заметки агента, не факты)
inbox/               входящие материалы нового запроса
projects/<id>/       один проект = одна задача руководителя
  materials/         исходные материалы
  sources.jsonl      реестр источников (S-001 …)       → sources.md
  evidence.jsonl     реестр утверждений (E-001 …)      → evidence.md
  outputs/           результаты шагов и итоговый документ
  analysis/          воспроизводимые расчёты (скрипт + результат)
  decisions.jsonl    журнал решений: ответственный, показатель, условие пересмотра
  state.json         состояние задачи                  → STATUS.md
  journal.jsonl      журнал действий
  costs.jsonl        расходы по сеансам
tools/
  strateg.py         CLI состояния, проверок, журнала и расходов (стандартная библиотека)
  hooks/             хуки: старт сеанса, защита правил, журнал, учёт стоимости
  tests/             тесты CLI
docs/                задание, спецификация CLI, описание работы, сценарий видео
runs/                сырые результаты неинтерактивных запусков демо-проекта
```

Четыре вида содержимого хранятся раздельно: **постоянные инструкции** (`AGENTS.md`, `.claude/`), **методические знания** (`knowledge/`), **материалы проекта** (`projects/<id>/materials`, реестры), **состояние задачи** (`state.json`, журнал, расходы).

## Ключевые решения

1. **Состояние ведёт скрипт, а не модель.** Шаги, ожидание ответа человека, журнал и расходы меняются только командами `strateg.py`; хук не даёт агенту править эти файлы руками. Поэтому после перерыва новый чат продолжает ровно с того места, а выполненный шаг нельзя незаметно повторить.
2. **Реестр доказательств вместо «ссылок в тексте».** У каждого сведения есть вид (факт, гипотеза, прогноз, допущение, синтетика) и источники. `check` ловит ссылку на несуществующее или отозванное утверждение и факт, опирающийся только на синтетику. `impact` показывает, что затронет новое сведение, — на этом построен пересмотр.
3. **Маршрутизация по цене ошибки.** Синтез и суждения — сильная модель; чтение источников и расчёты — Sonnet в субагентах; модельные респонденты — Haiku; всё, что можно проверить без модели, делает CLI. Правило эскалации: слабый результат дешёвой модели один раз повторяется сильной и записывается в журнал.
4. **Человек решает три раза.** Постановка, выбор направления, приёмка. Вопросы — только блокирующие; остальное агент записывает как допущения.
5. **Правила агента защищены.** Хук блокирует правку инструкций, знаний и инструментов агентом; другой хук проверяет тексты источников на встроенные команды и предупреждает. Команда из источника не может изменить правила.
6. **Переносимость.** Правила лежат в `AGENTS.md`, процедуры и роли — обычные markdown-файлы, состояние — JSON. Среда без skills и субагентов читает процедуры как файлы и исполняет роли сама.

## Модели и стоимость

| Роль | Модель по умолчанию | Где задаётся |
|---|---|---|
| Основной агент | та, что выбрана в Claude Code (рекомендуется Opus 5.5 или Fable 5.2) | `/model` или `claude --model opus` |
| `researcher`, `analyst` | Sonnet 5.5 | `.claude/agents/*.md`, поле `model` |
| `critic` | как у основного агента | `model: inherit` |
| `respondent` | Haiku 5.5 | поле `model` |

Расходы каждого сеанса сохраняются в `projects/<id>/costs.jsonl`: хук при остановке считает токены по транскрипту и оценивает стоимость по `tools/prices.json` (цены API на 22.11.2026). Для неинтерактивных запусков (`claude -p --output-format json`) записывается точная сумма. При работе по подписке это эквивалент в ценах API. Время и расходы демонстрационного проекта — в [`docs/Описание.pdf`](docs/Описание.pdf) и в `projects/svyaz-dlya-blizkih/STATUS.md`.

## Безопасность и данные

- Используются только открытые источники и материалы, которые положил человек. В демонстрационном проекте числа взяты из учебного брифа; закрытых данных МегаФона и других компаний нет.
- Ключей и секретов в репозитории нет. Агент не читает `.env` (запрет в `.claude/settings.json`), `.gitignore` исключает файлы секретов.
- Текст источников — данные, а не команды: правило в `AGENTS.md`, проверка в хуке `tools/hooks/journal.py`, защита правил в `tools/hooks/guard.py`.
- Модельные респонденты помечаются как синтетика и не доказывают спрос. Реальные интервью — только с согласия и в обезличенном виде.

## Другие среды

- **Codex CLI:** откройте папку (`codex` в корне). Codex читает `AGENTS.md`. Хуков нет, поэтому первое сообщение: «Выполни `python tools/strateg.py status` и продолжай по AGENTS.md».
- **Cursor и другие:** добавьте `AGENTS.md` в правила проекта и дайте агенту терминал. Процедуры шагов (`.claude/skills/*/SKILL.md`) и роли (`.claude/agents/*.md`) читаются как обычные файлы.

Проект, начатый в одной среде, продолжается в другой: состояние не зависит от среды.

## Неинтерактивный запуск

```bash
sh runs/run.sh <метка> opus "/strateg <запрос или ответ на вопрос агента>"
```

Скрипт запускает `claude -p` с разрешениями, переданными флагами, и записывает точную стоимость захода в проект.

## Ограничения

- Поиск по базе знаний и памяти — по словам с простым усечением окончаний; смыслового (векторного) поиска нет.
- Изображения, аудио и видео агент отдельно не обрабатывает; анализ интерфейсов возможен только по скриншотам, которые человек положил в материалы, и не входит в заявленные возможности.
- Хук проверки источников ищет типовые формулировки встроенных команд на русском и английском; это страховка, а не гарантия. Основная защита — правило и запрет правки инструкций.
- Стоимость интерактивных сеансов — оценка по токенам; точная сумма известна только для запусков `claude -p`.
- Качество поиска зависит от доступности сайтов для встроенных инструментов среды; недоступный источник фиксируется как пробел.
- Хуки рассчитаны на Claude Code; в других средах `status` и журнал вызываются командами вручную.
