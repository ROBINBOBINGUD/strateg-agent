# memory — память между проектами

`notes.jsonl` — заметки агента, которые переживают отдельный проект: уроки, повторяющиеся приёмы, прежние выводы. Записи добавляет и отзывает только CLI:

```
python tools/strateg.py memory add --kind lesson --text "…" --origin "<проект>, <E-id>"
python tools/strateg.py memory revoke M-001 --reason "…"
python tools/strateg.py memory list
python tools/strateg.py search "<запрос>"
```

Правила:

- Заметка — это вывод агента, а не факт. В новом проекте её можно использовать только как гипотезу, пока она не подтверждена источником этого проекта. Поиск выводит заметки с пометкой «заметка агента, не факт».
- Устаревшая или ошибочная заметка не удаляется, а отзывается с причиной — так видно, что и почему перестало считаться верным.
- Сведения о конкретном рынке или компании в память не пишутся: они живут в `evidence.jsonl` своего проекта вместе с источниками.
