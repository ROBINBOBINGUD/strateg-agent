# Сценарий видео: сквозной путь демонстрационного проекта

> **Как ролик сделан на самом деле.** Этот сценарий описывает живую запись, от которой пришлось отказаться: на повторный полный прогон не хватало лимита использования. Итоговый ролик (8 минут 14 секунд) собран воспроизведением транскриптов настоящих сеансов демонстрационного проекта: `docs/video/replay.py` выводит каждое действие агента и субагентов с исходным временем, реплики человека и ответы агента, `docs/build/final_video.py` добавляет титры. Ролик: https://github.com/ROBINBOBINGUD/strateg-agent/releases/download/video/strateg-demo.mp4

Итоговое видео — до 10 минут. Живая запись длиннее (агент работает 30–40 минут), поэтому периоды, когда агент работает сам, ускоряются при монтаже и подписываются («×12: агент читает источники»). Моменты, где человек вводит запрос, отвечает и принимает решение, идут в обычной скорости. Ничего не вырезается и не переснимается.

## Что делает Владимир

Только пять вставок текста и одно закрытие чата. Запись окна и монтаж делает Claude.

### Подготовка (один раз, 1 минута)

1. Claude сделает чистую копию репозитория (`Desktop\strateg-demo`, как у жюри после `git clone`), откроет в ней отдельное окно терминала с заголовком `Strateg-demo` и включит запись именно этого окна (`docs/video/start.ps1`). Другие окна в запись не попадают — можно параллельно заниматься другими делами, но окно `Strateg-demo` нельзя сворачивать и менять его размер.
2. В этом окне выполнить:

```powershell
claude --setting-sources project,local --strict-mcp-config --model opus
```

Если появится вопрос о доверии к папке — выбрать «Да, доверяю». Флаги отключают личные настройки и MCP-серверы: агент работает только на том, что лежит в репозитории, как у жюри.

### Реплика 1 — запрос (0:00)

```
/strateg Новый проект. Я руководитель направления «Связь для близких и собственных устройств» у мобильного оператора. Бриф и таблица исходных показателей лежат в inbox/ (megafon-brief.md и megafon-pokazateli.csv). Мне нужно понять, кому помогать первым — семьям или владельцам нескольких номеров, — что именно менять и стоит ли оператору вкладывать в это деньги. К концу первого квартала я должен решить, выделять ли людей и деньги на пилот.
```

Агент создаст проект, прочитает бриф и таблицу, покажет постановку и задаст один-два вопроса. Ждать 2–3 минуты.

### Реплика 2 — ответ на вопросы (после вопросов агента)

```
Постановку подтверждаю. Реальных данных оператора нет: работаем на учебных числах брифа и открытых источниках, недостающее берём как допущения с диапазонами. Нужен полный документ из пяти частей, как в брифе; в нём должны быть видны продуктовая стратегия, коммуникационная стратегия и план проверки. Продолжай до выбора направления.
```

Если агент задаст вопрос с вариантами (окно выбора) — выбрать вариант «по умолчанию» или вписать этот текст в «Другое».

Агент сам пройдёт сбор материалов, исследование (несколько субагентов ищут источники параллельно, аналитик считает) и варианты. Ждать 12–18 минут. Если появится запрос разрешения на команду `python …` — разрешить.

В конце агент покажет сравнение вариантов и спросит, какой берём.

### Перерыв — закрыть чат (не отвечая на вопрос)

Набрать `/exit`. Затем в том же окне:

```powershell
python tools/strateg.py status
```

Видно: шаги 1–3 закрыты, шаг «Варианты» ждёт ответа человека. Состояние лежит в файлах, а не в чате.

### Реплика 3 — новый чат, продолжение

Снова запустить ту же команду `claude --setting-sources project,local --strict-mcp-config --model opus` и вставить:

```
Продолжаем. Берём вариант, который ты рекомендуешь. Доводи до итогового документа.
```

Агент получит статус от хука, запишет ответ и пройдёт продуктовую стратегию, коммуникационную стратегию, план проверки и сборку с независимой критикой. Ждать 15–20 минут. В конце он спросит: принять или доработать.

### Реплика 4 — приёмка

```
Принимаю.
```

### Реплика 5 — новые данные после решения (дополнительный уровень)

```
/revise Пришли новые данные: владелец системы расчётов сообщил, что остатки пакета обновляются с задержкой до 4 часов, а не в реальном времени. Что это меняет?
```

Агент найдёт затронутые утверждения, разделы и решения и обновит только их. Ждать 3–5 минут.

### Финал

Набрать `/exit`, затем по очереди:

```powershell
python tools/strateg.py status
python tools/strateg.py cost
python tools/strateg.py journal --tail 20
```

После этого написать Claude «запись готова» — он остановит запись и смонтирует ролик.

| 0:00–0:20 | Титр: что это за агент, какая задача, какие модели | — |
| 0:20–1:10 | Запуск Claude Code в папке агента, реплика 1 | ×1 |
| 1:10–1:50 | Агент читает бриф, пишет постановку | ускорено |
| 1:50–2:40 | Постановка и вопросы агента, реплика 2 | ×1 |
| 2:40–4:10 | Сбор материалов, субагенты-исследователи, расчёты, критик | ускорено, с подписями шагов |
| 4:10–5:10 | Сравнение вариантов и вопрос «какой берём» | ×1 |
| 5:10–5:40 | `/exit`, `status`: состояние сохранено | ×1 |
| 5:40–6:10 | Новый чат, реплика 3, агент называет место остановки | ×1 |
| 6:10–7:40 | Две стратегии, план проверки, сборка, критика | ускорено, с подписями шагов |
| 7:40–8:20 | Итог и вопрос о приёмке, реплика 4 | ×1 |
| 8:20–9:10 | Реплика 5: пересмотр при новых данных | ускорено, результат ×1 |
| 9:10–9:50 | `status`, `cost`, `journal`; титр со ссылкой на репозиторий | ×1 |

## Если что-то пошло не так

- Агент остановился с ошибкой сети или лимита — снова запустить `claude …` и написать «продолжай»: он продолжит с сохранённого шага, это тоже годится для видео.
- Агент долго молчит — это работают субагенты; в строке состояния видно число активных задач.
- Окно случайно закрыто — написать Claude, запись перезапустится, работа агента не потеряется.
